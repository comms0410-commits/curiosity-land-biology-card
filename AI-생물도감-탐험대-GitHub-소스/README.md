# AI 생물도감 탐험대

초등학생이 생물의 특징을 관찰하고, 규칙 기반 분석을 체험하며, 생물도감 카드와 친구 퀴즈를 만드는 정적 웹앱입니다.

## 실행하기

1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저에서 엽니다.

빌드 도구, 서버, API 키, 외부 라이브러리가 필요하지 않습니다. GitHub에 올린 뒤 GitHub Pages로 배포할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 압축을 푼 폴더 안의 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포할 브랜치(보통 `main`)와 폴더(`/ root`)를 선택하고 저장합니다.
4. 잠시 후 GitHub Pages가 안내하는 주소에서 사이트를 확인합니다.

## 주요 기능

- 식물·동물·곤충·새·바다생물·상상 생물 6개 분야
- 분야별 샘플 생물 선택과 나만의 상상 생물 이름 입력
- 색깔·크기·모양·사는 곳·움직임·특별한 점 관찰
- 규칙 기반 유사 특징 분석과 초등학생용 AI 설명
- 나의 호기심 질문, 점수, 배지가 포함된 도감 카드
- 단계별 힌트와 정답 공개가 있는 친구 퀴즈
- 퀴즈 문장 복사, 카드 인쇄 및 PDF 저장
- 모바일·태블릿 반응형 레이아웃

## 교육상 안내

이 버전은 실제 AI API를 호출하지 않습니다. 샘플 생물의 특징과 학생 선택을 비교하는 규칙 기반 체험입니다. 분석 결과는 정답이나 확률이 아니라 특징 비교 결과이며, 실제 생물을 관찰하고 확인하도록 안내합니다.
